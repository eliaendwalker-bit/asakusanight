# AsakusaNight

_A cinematic Unreal Engine boss-fight demo set in Asakusa, with victory minting an on-chain relic NFT_

## Summary

A vertical-slice 3D action demo built in Unreal Engine 5, featuring one beautifully rendered Asakusa street scene and a boss battle against a dark organization enforcer. Defeating the boss triggers a Solana wallet connection that mints a unique 'Spirit Seal' NFT as proof of victory, showcasing how AAA-quality visuals can merge with on-chain ownership.

## Target users

Game players, NFT collectors, and hackathon judges evaluating graphics-driven Web3 games

## Problem

Most Web3 games have weak graphics and shallow gameplay, while this team has strong 3D/Unreal skills but no blockchain experience to showcase them in a crypto hackathon.

## Solution

Build one gorgeous, playable combat scene in Unreal Engine and bolt on a minimal Solana integration so a real game moment (boss defeat) produces a verifiable on-chain reward.

## MVP features

- One fully modeled Asakusa street environment (Kaminarimon-inspired) with dynamic lighting
- Single boss encounter with combo attacks, dodge, and defeat cinematic
- Solana wallet connect screen triggered after boss defeat
- Mint of a 1-of-1 'Spirit Seal' NFT via Metaplex on victory
- Simple HUD showing health, stamina, and wallet status

## Chains

Solana

## Tech

Unreal Engine 5, Blender, Metaplex Core, Solana Wallet Adapter, Node.js backend for mint trigger, Nanite/Lumen

## Category

Gaming

## Why now

Solana's fast, cheap minting plus Metaplex's compressed NFTs make it feasible to tie a real-time gameplay moment to an on-chain mint within a hackathon timeframe.

## Roadmap

- Expand to a full chapter with multiple enemies and story beats
- Add dynamic NFT traits that evolve based on player performance
- Explore mobile/cloud streaming to reach players without high-end PCs
